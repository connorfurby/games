# UI

## Density contract

Shell mirrors Grocery Empire chrome (own files, no GE CSS imports):

- **App grid:** HUD top · hub rail left (desktop) / bottom bar (phone) · main.
- **Hud:** brand · cash/clarity/stars · Next Goal shelf-tag · transport (pause/speed/undo) · More · hanging alert.
- **HubHead:** `Department / Section` + GE-style subtab bar when a hub has more than one section.
- **Keys:** `1–5` hubs · `Space` pause.

Every hub uses **PlayFrame**: one purpose line → room → VerbTray (one primary + ≤4 secondaries) or Air’s custom hero board → optional body.

### Air loop

One hero verb by priority: **Air** (spend ready log) → **Log** (buffer full) → **Hold** (press-and-hold free tomato) → **Sweep**. Secondaries keep Dial/Lock/Log/Air reachable. Room strip: Clarity · Buffer · Ready. Format pills, then the two shows for that format. Shack hits are interactive.

- Phone bar: Air · Plant · Crew · Books · Net. Wiki + Museum live in **More**.
- Kit under `ui/kit/` (Button tones primary/free/ghost/danger/secondary — solid free tomato / shelf-tag gold). No Grocery imports.
- Shack: RoomHits for Dial/Lock/Log/Air, RoomHud chips, era-gated props. Purchases change the room.
- Coach: corner offer card; continuous opening tour with spotlight.
- Must play at **390 px**. `reducedMotion` respected.
- Version chip: More only — not in HUD.
- Dev: `/play/signal-decay/dev` — stages Opening / Era 2 / Quiet / Dial / Last Carrier + Buy Best.

## Late presentation (eras 3–12)

- **Plant · Desks:** Heat log (3) · Band plan (4, exam / clean / fast) · Birds (5) · Quiet door (6, two laws + one carry).
- **Plant · Mast:** quantity stepper on the antenna.
- **Plant · Trees:** pannable skill board, one family at a time (Antenna through Capital). Tiers are eras. A link is the path (same stat, else the previous era) and lights when that rank is owned. Buying stays open — the link does not gate. Ranks past the era show as ahead. Phone opens the buy sheet.
- **Chapters:** each era opens a card (voice, epigraph, three mission lines) before the coach. `chapterSeen` remembers the accept. The walkthrough offered next prefers the current era. `?` repeats the mission. Next strip uses the mission line when a goal has no closer hint.
- **Net · Map:** quantity stepper on towers; each relay is match / push / quiet.
- **Books · Calls:** doctrine ladder from Night Skip. Retune sheet (and the Quiet door) pick one doctrine or one show.
- **Next strip:** one aside (late bill, Choir hum, hot trait, waiting caller, open lane) that hides when it would restate the goal.
- **Quiet door sheet:** stamp ledger, pick up to two laws, then Stay / Retune / Sign off.
- **Net · Dial:** reel · route · season · phrase · charter · last via `DialBoards.tsx`.
- **Whispers:** `WhisperToast` every 90 s game time.
- **Rivals:** Pirate, MetroWave, Orbital, Choir (era ≥ 7) on Crew · Rivals.
