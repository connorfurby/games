## Patterns

- Read state via `useGame()` / selectors; mutate only with `dispatch(command)`.
- **PlayFrame** (`ui/play/`) is the page frame: purpose → room → verb tray → optional body. `ScreenPanel` / `LateHubShell` / `HubStage` wrap it. Prefer real `tray` props over `primarySlot`.
- **Button law** — `primary` = spend (tag yellow); `free` = one free verb (tomato); `ghost` = dismiss/Done (default); `danger` = destructive confirm.
- **Phone bar** — Store, Supply, Team, Money, Hubs. Money stays when Worlds unlocks; Empire/Worlds/Museum live in the Hubs sheet.
- **RoomScene** standard for department art: dense ~960×300, `RoomHud` chips, tappable `Hit` regions (see decision log in `docs/2.0-plan.md`).
- Kit: `ui/kit/` — ScreenHeader, Button, Card, Meter, Sheet (focus-trapped), ConfirmProvider, EmptyState. Play helpers: VerbTray, ActionRow, StatusChip, FailReason.
- CSS layers: `legacy` (grocery.css + g2.css) is **lowest**. Kit / shell / panels / scenes / motion win. Unlayered CSS is forbidden.
- Respect `reducedMotion` (including `Hit` / Coach scroll / crate hop).
- **Must play at 390 px.**

### Number law (4.0)

- Crowded chips / HUD / Shelf glance **always** use Named shorthand (`qty` / `money` / `formatBN`), even if Settings is Full.
- Full remains for Books detail and infinite-space tooltips.
- Stat values: `min-width: 0`, overflow ellipsis, tabular nums.

### Best buttons (4.0)

- Upgrades: **Upgrade Best** (active tree) + **All trees**; confirm when plan ≥8 ranks. Capstones stay opt-in.
- Memos: **Buy Best** value-order desk sweep (effect/cost, then cheapest); Archive/Analyst/office capacity stays manual.

### Density contract

- **One title** — hub purpose visible; PlayFrame `department` names the subtab.
- **One home per number** — HUD: cash, rate, baskets; Room: shelf, back, price; Tray: cost/cooldown under the finger.
- **HUD has no version chip** — Bulletin · v4.0 lives on News / More / Settings only.
- **One primary verb** — VerbTray primary; editors live in `Sheet` at every width.
- **Nothing empty** — do not mount cards for zero trucks, no loyalty, locked next-era projects, etc. Use kit `EmptyState`.
- **Room or band, not both** — `RoomHud` chips carry the numbers.
- **One guidance channel** — Next Goal is the spine. SuggestTip hides when it restates the goal action.
- **Verb palette** — tag yellow (`tone="primary"`) = paid spends; tomato (`tone="free"`) = the single free verb; Done / dismiss = `ghost`. Default Button tone is `ghost`.
- **Phone bar** — Store · Supply · Team · Money + Hubs sheet (Empire / Worlds / Museum). Money stays when Worlds unlocks.
- **One coach at a time** — while `tutorials.active`, hide SuggestTip and ambient toasts; queue capped + calm window after each lesson; Era openers enqueue one tour (rest in Coach catalog).
- **Shell chrome** — [`ShellFrame`](../../src/shell/ShellFrame.tsx) wraps News / Guide / Shop / Awards and overlays Home. Primary nav: Play · News · Guide · Awards · Shop + `v{GAME_VERSION}` (News only) + waffle (Home / Play / Settings / Keys / Dev). Awards lives only in the bar. Play keeps its own HUD (no ShellFrame).
- **News desk** — warm receipt bulletin on wood-tint page. `GAME_VERSION` in [`content/news.ts`](../../src/games/grocery-empire/content/news.ts) (not `SAVE_VERSION`). Routes `/news` + `/news/:id`; Shelf detail has one “What’s new” receipt line. `/news` opens the newest receipt above the list; the list filters by era band (`NewsArticle.bands`: 0–1 / 2–3 / 4–6 / 7–12 / meta). Always prepend an article when shipping player-visible changes.
- **4.0 real panels** — Fleet harbor, Empire rank ring (last/next only), Planets sticky wants + Commit/File tray, Memos desk (Buy Best, collapsed back office after spine ≥3), Upgrades PlayFrame + Upgrade Best. Strategy full doctrine ladder + hall. Marketing Celebrity in sheet; Staff hire primary + annex ActionRows. **SAVE 32:** Staff shows a policy `Disclosure` per unlocked department (button + blurb); Flyer Desk sheet carries the rival-stance line; Cold shows a blast/tunnel FailReason; Land shows the hot trait + matching policies. Cross-links: Strategy↔Memos Att, Build→Suppliers when full, Fleet→Strategy on Read, Cold brownout FailReason, Books↔Build upkeep.
- **Phase 0 shell** — Worlds panels and Upgrades pass `hub` on `ScreenHeader` when still used. Museum keeps the gallery and opens on one card per wing (a wing's wall renders only when chosen). Suppliers invoice book is a one-line status plus a `Sheet`. `DepartmentBands` and `StatusBand` are deleted.

## Wave D shell rules (4.0)

- **Version:** the Bulletin chip (`GAME_VERSION`) shows only on News, More, and Settings (plus the shell bar on `/news`). Never on the HUD or play chrome.
- **Settings** is one calm column (`.settings-modal`, `.ge-more`, `.g2-tools .ge-more-fields`). News list is a dense two-row grid (`.news-list__row`).
- **Cross-links:** Strategy short Att → opens the Memos drawer (`requestInbox`); Memos short Read → Strategy; Build storage full → Suppliers; Fleet short Read → Strategy; Cold brownout → `FailReason` + `cold-sign-log` coach id; Build upkeep ↔ Books.
- **Wrap segmented rows:** `className="gk-seg--wrap"` on a `SegmentedControl` (Fleet pockets) grids it instead of hiding a horizontal scroll.
- `.fl-dock` and `.ge-floor*` CSS is deleted; Unpack lives in the PlayFrame tray (`.ge-unpack`).

## 40.0 Phase 10 visual system

No `SAVE_VERSION` bump — presentation only.

- **Shell layer:** the live chrome now resolves from `@layer shell` in `ui/shell/shell.css` — `.g2-hud*`, `.g2-stat*`, `.g2-goal*` (Next Goal bar), `.g2-hubs` / `.g2-hub*`, `.g2-hubhead*`, the menu drawer / inbox (`.g2-inbox*`, `.g2-tools*`, `.g2-scrim`) and the command palette (`.g2-palette*`). `g2.css` stays in `legacy` for everything else (tokens block, scene art, panels, `.g2-tag`, `.g2-subtab`); do not re-add the moved selectors there. `grocery.css` is untouched.
- **Layer gotcha:** a later layer wins regardless of specificity. If you add a rule for a moved selector, put it in `shell.css`; a legacy rule for the same element will lose.
- **Night case:** `--sc-night-*` tokens (`design/sceneTokens.css`) feed Rank Hall, Strategy Hall, Upgrades Hall and the empire map sky/ground. Palette law is unchanged: tomato = free verb, tag yellow = spend, no third accent.
- **Thin rooms:** Upgrades gets `UpgradesHallScene` (one plaque per tree, tap = pick the tree; yellow ring on the active tree and a yellow dot where a rank is affordable). The Trees control stays under it for phones; the tree stays the body. Era 1 Land shows `EarlyLandStreet` (the one open door plus three LEASE lots) above the existing EmptyState.
- **Beats** (all optional garnish, off under `reducedMotion` / `html.ge-reduced-motion` / OS setting): second regular fades in with two opacity pulses in `FloorRoom` (`.rm-arrive`, live rooms only); Logistics manifest stance ✓ pops (`useBeat` + `Beat`); Cultivar bed lock chip thunks once and a `ShelfFill` meter drains to the season turn; Charter shows a `Seated n/3` meter (`ShelfFill`) and a `CrateHop` crate when a clause lands. No map spin; brownout unchanged.
- **Shop cosmetics in rooms:** ledger skin also dresses the Books room (`.ls-skin--*`), unpack FX also reach the Floor room's Unpack station (`.rm-hit--unpack`), and equipped ornaments hang on the Fleet harbor pier (`HarborOrnaments`). ShopPage tabs say where each one shows. No new packs; none touch the sim.

## 40.1 site shell + Ops Wiki

- **Tokens everywhere:** `html.shell-ds` gets the `.ge-root` token set, so kit components (`Button`, `LinkButton`, chips) look the same on Home, News, Guide, Shop, Awards and Settings as in play. Site primitives are `sd-*` in `src/shell/ds.css` (`@layer kit`): `sd-page`, `sd-eyebrow`, `sd-title`, `sd-lede`, `sd-section-head`, `sd-tabs`/`sd-tab`, `sd-chip`, `sd-stats`, `sd-tagprice` (token prices), `sd-coin`.
- **Button law on the site:** tomato = the one free verb (Start/Continue, Play this lesson, Play); tag yellow = spends tokens (Buy); `secondary` = equip / open a department; ghost = navigation and dismiss; danger = wipe. Do not use raw `<button>` styling for actions on shell pages.
- **Page CSS:** `home.css`, `news.css`, `shop.css` live beside their pages (unlayered like `index.css`, all class names prefixed `hm-`, `nw-`, `sp-`). The wiki CSS is layered (`@layer panels`) because it also renders inside play.
- **Wiki routes:** `/guide/grocery-empire` (home), `/a/:id`, `/topic/:id`, `/learn[/:id]`, `/atlas[/:era]`, `/glossary[/:id]`, `/hubs`, `/search?q=`. Old `?a=` links still open the article. In play: Menu → **Wiki**.
- **Writing wiki content:** keep writing `content/guide.ts` in its plain style (ALL-CAPS heading lines, two-space indented lines, `1.` steps, `□` checks, `· ` bullets, `Term — definition`, `A → B → C` flows, `SEE ALSO  Title`) — the parser renders it. For diagrams, add an `INSERT` entry in `content/wiki/articles.ts`; for a fully designed page, add a `RICH` entry. Glossary words in `content/wiki/glossary.ts` auto-link on first mention.

## 1.0 rules added 2026-11-16

- **Type scale only.** `font-size` in game UI CSS is a `--t-*` token. Raw px is allowed only for SVG scene text (see `design/typeScale.test.ts` for the file list).
- **Blocked buttons** stay in their colour family (tinted, dashed). Never grey them out by hand; pass `disabled` or `affordable={false}`.
- **Rooms on phones.** `RoomScene` gives every room chips-as-text plus a pannable band. Pass `portrait={{ w, h }}` and branch on `usePhone()` only when you re-lay the stations (Floor does). Do not put numbers only inside the SVG: they must be in `chips`.
- **Primary verb** goes through `PlayFrame tray`; on phones it is sticky at the page bottom. Do not build a second sticky footer in a panel.
- **Help.** Tips belong to a room: add the id to `TIP_MENU`. A department gets its `?` for free from `PlayFrame`; make sure a wiki article lists the menu in `MENUS_FOR`.
- **Next Goal** has one button. Do not add links or second actions to it.
- **Chips** hug their text and are sentence case. No full-width outlined status bars.
- **No layout shift (law 13).** Nothing may appear or disappear during play in a way that moves another control. Reserve the row, or position the newcomer over an edge (see `.g2-alert--hang`).
- **Overlays portal.** Use kit `Sheet`/`Modal`; never hand-roll a fixed panel inside a department.
- **Pickers are Fields.** A choice is a `Field` (label + `SegmentedControl`/`Stepper`/`Toggle`) inside a `FieldSet`. No unlabelled chip rows.
