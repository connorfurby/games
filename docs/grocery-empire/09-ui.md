# UI structure

## Hubs

Defined in `ui/shell/hubs.ts`:

| Hub | Early menus | Late / Worlds growth |
| --- | --- | --- |
| Store | Floor, Backroom, Build | Off-world bay, facings, regulars, planogram |
| Supply | Suppliers, Cold, Logistics | Invoices, cooler log, dispatch, bonded |
| Team | Staff, Marketing, Rivals, Ventures | Shift board, flyer desk, annex roles |
| Money | Books, Invest, Politics | Star-aware books, instruments, council |
| Empire | Empire, Map, Upgrades, Strategy, Land, Fleet | Pocket Ops, rank hall |
| Worlds | Planets → Exchange → Cultivars → Signal → Charter → Last Aisle | Practice scores, hearing |

Coach / More sit in HUD chrome, not as a seventh hub.

## Patterns

- Read state via `useGame()` / selectors; mutate only with `dispatch(command)`.
- **PlayFrame** (`ui/play/`) is the page frame: purpose → room → verb tray → optional body. `ScreenPanel` / `LateHubShell` / `HubStage` wrap it. Prefer real `tray` props over `primarySlot`.
- **Button law** — `primary` = spend (tag yellow); `free` = one free verb (tomato); `ghost` = dismiss/Done (default); `danger` = destructive confirm.
- **Phone bar** — Store, Supply, Team, Money, Hubs. Money stays when Worlds unlocks; Empire/Worlds/Museum live in the Hubs sheet.
- **RoomScene** standard for department art: dense ~960×300, `RoomHud` chips, tappable `Hit` regions (see decision log in `docs/2.0-plan.md`).
- Kit: `ui/kit/` — ScreenHeader, Button, Card, Meter, Sheet (focus-trapped), ConfirmProvider, EmptyState. Play helpers: VerbTray, ActionRow, StatusChip, FailReason.
- CSS layers: `legacy` (grocery.css + g2.css) is **lowest**. Kit / shell / panels / scenes / motion win. Unlayered CSS is forbidden.
- Respect `reducedMotion` (including `Hit` / Coach scroll / crate hop).
- **Must play at 390 px.**

### Density contract

- **One title** — hub purpose visible; PlayFrame `department` names the subtab.
- **One home per number** — HUD: cash, rate, baskets; Room: shelf, back, price; Tray: cost/cooldown under the finger.
- **One primary verb** — VerbTray primary; editors live in `Sheet` at every width.
- **Nothing empty** — do not mount cards for zero trucks, no loyalty, locked next-era projects, etc. Use kit `EmptyState`.
- **Room or band, not both** — `RoomHud` chips carry the numbers.
- **One guidance channel** — Next Goal is the spine. SuggestTip hides when it restates the goal action.
- **Verb palette** — tag yellow (`tone="primary"`) = paid spends; tomato (`tone="free"`) = the single free verb; Done / dismiss = `ghost`. Default Button tone is `ghost`.
- **Phone bar** — Store · Supply · Team · Money + Hubs sheet (Empire / Worlds / Museum). Money stays when Worlds unlocks.
- **One coach at a time** — while `tutorials.active`, hide SuggestTip and ambient toasts; queue capped + calm window after each lesson; Era openers enqueue one tour (rest in Coach catalog).
- **Shell chrome** — [`ShellFrame`](../../src/shell/ShellFrame.tsx) wraps News / Guide / Shop / Awards and overlays Home. Primary nav: Play · News · Guide · Shop + `v{GAME_VERSION}` + waffle (Awards / Settings / Keys / Dev). Play keeps its own HUD (no ShellFrame).
- **News desk** — warm receipt bulletin on wood-tint page. `GAME_VERSION` in [`content/news.ts`](../../src/games/grocery-empire/content/news.ts) (not `SAVE_VERSION`). Routes `/news` + `/news/:id`; Shelf detail has one “What’s new” receipt line; More still links `/news`. Always prepend an article when shipping player-visible changes.
- **Phase 0 shell** — Worlds panels and Upgrades pass `hub` on `ScreenHeader` (stats and actions only; the hub H1 is the title). Museum keeps the gallery and drops the competing “Relic Museum” heading. Suppliers invoice book is a one-line status plus a `Sheet`. Empire rank stays on the header Stat; the doctrine board is a `Disclosure` (`defaultOpen` while fewer than two doctrines are owned). Autonomous stays one line until release can succeed. `DepartmentBands` and `StatusBand` are deleted.
